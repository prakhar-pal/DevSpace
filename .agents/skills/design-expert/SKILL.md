# Skill: UI/UX Design Expert

## Desktop App & Web UI Patterns
1. **Layout & Navigation:**
   - **Sidebar Navigation:** Use a persistent left sidebar for primary navigation (managing workspaces/pods), crucial for desktop applications.
   - **Information Density:** Balance whitespace with the need for data density in a developer tool. Professional tools often benefit from tighter layouts compared to consumer web apps.
   - **Master-Detail View:** Select an item in the sidebar (master) to view its full details and actions in the main area (detail).

2. **Interaction & Feedback:**
   - **Real-time Status:** Provide immediate visual feedback for ongoing processes (e.g., pod starting, stopping) using spinners, progress bars, and status badges.
   - **Contextual Actions:** Use context menus (right-click) or inline action buttons for item-specific commands.
   - **Keyboard Shortcuts:** Implement robust keyboard navigation and shortcuts for power users.

3. **Visual Aesthetics:**
   - **Consistency:** Maintain a consistent design language (colors, typography, spacing) using a design system or component library.
   - **Dark Mode:** Essential for developer tools. Ensure high contrast and accessible color palettes in both light and dark themes.
   - **Clear Hierarchy:** Use typography (size, weight) and color contrast to guide the user's eye to the most important information.
